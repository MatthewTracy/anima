# core/memoirs — see `src/governance/autobiographies.js`

> The memoirs primitive (endgame first-person reflection — lighter than soul evolution, produces shareable per-game artifacts) currently lives in **`src/governance/autobiographies.js`** in the legacy Forum scenario layout.

This directory is a reserved migration target. When the Forum scenario migrates to the unified `scenarios/<name>/runner.js` shape, the memoir primitive moves here under `core/memoirs/`. Until then, this directory is intentionally empty so:

- Listings of `core/` show the memoir layer is a real primitive
- Anyone looking here finds this README pointing at the right code
- The future migration target is reserved at the obvious path

See [`docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md) for the broader migration plan.
